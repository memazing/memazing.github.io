How connection works

Claude MCP (local) is a private, internal tool with no public connection flow. There is no marketplace-style “Connect to QuickBooks” button, because the Software is not distributed and has no external users.

The OAuth 2.0 handshake with Intuit is initiated locally by the Company’s operator on the machine that runs the Software. The resulting refresh token is stored only on that machine and is not transmitted to any hosted service.

Reconnection follows the same local procedure. This page exists to satisfy Intuit’s application-registration requirements.
