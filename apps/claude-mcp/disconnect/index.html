Disconnecting Claude MCP (local)

Because the Software has no external users, there is no user-initiated disconnect flow served from this URL. This page exists to satisfy Intuit’s application-registration requirements.

To disconnect the Software from a QuickBooks Online company:

  • Revoke the app’s access from the connected company’s QuickBooks Online settings (Settings → Apps → Connected Apps), and
  • Delete the local OAuth credentials from the operator’s machine (the .env file used by the Software).

Once revoked at either end, the Software can no longer read QuickBooks data on behalf of the disconnected company. The Software does not retain a copy of QuickBooks record data.
