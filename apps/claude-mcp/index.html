About

Claude MCP (local) is a private, internal-use tool operated by Memazing, Inc. on Company-controlled hardware. It is a locally-run instance of an open-source Model Context Protocol server that connects the Company’s own QuickBooks Online company file to AI tooling used by the Company’s officers.

The Software has no web interface and no external end users. It is not listed in the Intuit App Store and is not distributed to any third party. This page exists to satisfy Intuit’s application-registration requirements.
