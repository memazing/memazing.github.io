Privacy Policy

Effective date: 2026-08-20
Application: Claude MCP (local) (the “Software”)
Operator: Memazing, Inc. (the “Company”)

1. Scope

The Software is an internal tool operated by the Company on Company-controlled hardware. It has no external end users. The only person whose data is accessed through the Software is the Company itself, via the Company’s own QuickBooks Online account.

This policy describes what happens to that data when the Software runs.

2. Data Accessed

Through the Intuit OAuth 2.0 flow, the Software is authorized to read the Company’s QuickBooks Online company file, including accounting records such as accounts, transactions, customers, vendors, and reports. Access is read-only in the Company’s configuration.

3. Where the Data Goes

  • Local processing. QuickBooks data is fetched from Intuit’s API to the Company-controlled machine on which the Software runs and is held in memory only for the duration of a request.
  • AI provider. When the Company’s operator invokes the Software from an AI coding assistant (currently Anthropic’s Claude Code), the specific QuickBooks fields returned by a given tool call are transmitted to Anthropic as part of the assistant’s context. Anthropic’s handling of that data is governed by Anthropic’s own terms and privacy commitments.
  • No other third parties. The Software does not transmit QuickBooks data to any other service, does not log it to any remote destination, and does not persist it beyond the operator’s local machine.

4. What Is Stored

The Software persists only the OAuth credentials required to reach the Intuit API (client identifiers and refresh token), in a local configuration file on the operator’s machine. QuickBooks record data itself is not stored by the Software.

5. Security

Credentials are stored on the operator’s machine under standard file permissions. The Software is not exposed on any network port and does not accept external connections.

6. Retention

OAuth credentials are retained until the operator revokes access (via the Intuit developer dashboard or by deleting the local configuration file). Because the Software does not persist QuickBooks record data, there is no additional retention to disclose.

7. Changes to This Policy

Material changes will be reflected here with an updated effective date. Because there are no external end users, no additional notice mechanism is provided.

8. Contact

Questions regarding this policy may be directed to contact@memazing.com.
